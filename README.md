# RYZE — Premium Marketplace

### Stack
*   **Frontend:** React 18 + Vite + Tailwind CSS + Framer Motion
*   **Auth & Database:** Firebase Auth + Firestore
*   **Storage:** Firebase Storage
*   **Payments:** Razorpay
*   **Hosting:** Vercel

### Features
*   Staff dashboard — manage inventory, orders, analytics
*   Firebase Auth with email/password sign-in
*   Cart, wishlist, order tracking
*   Razorpay payment integration (COD supported too)

### Dev
```
npm install
npm run dev
```
